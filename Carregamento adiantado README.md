## Carregamento adiantado

- **Carregamento adiantado** o que significa que os dados relacionados são carregados do banco de dados em uma única cosulta
- **Carregamento explícito** significa que os dados relacionados são explicitamente carregados do banco de dados em um momento posterior
- **Carregamento lento** significa que os dados relacionados são carregados sob demanada do banco de dados quandoa propriedade de navegação é acessada
